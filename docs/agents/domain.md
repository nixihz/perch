# 领域文档

本仓库采用 single-context 布局。工程类 skill 按以下约定读取和使用领域文档。

## 探索前读取

- 根目录 `GLOSSARY.md`：项目领域术语及其定义。
- `docs/adr/`：与本次工作范围相关的架构决策记录。

文件或目录不存在时，直接继续工作，不为缺失单独提示，
也不预先创建空文件。术语或决策实际确定后，再由 `/domain-modeling`
按需创建或更新；本配置不会安装或启用该 skill。

## 文件布局

- `GLOSSARY.md`：全仓共享术语表。
- `docs/adr/NNNN-<slug>.md`：架构决策记录。

## 沿用术语

事项标题、重构建议、分析假设、测试名称等涉及领域概念时，
使用 `GLOSSARY.md` 中定义的名称，避免使用术语表明确排除的同义词。

需要的概念尚未收录时，先核对是否符合项目现有用语；
确有缺口时，留给 `/domain-modeling` 处理，不自行编造定义。

## 显式说明决策冲突

建议或实现若与已有 ADR 冲突，明确指出对应 ADR、冲突内容和重新讨论的理由，
不要静默覆盖既有决策。
