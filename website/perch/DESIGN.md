# Perch 介绍与下载网站

沿用根目录 DESIGN.md 的纸白、暖墨与陶土红品牌。页面使用宽留白、编辑式大标题、细分隔线，主操作为下载 macOS 版本。用标明“工作流程示意”的静态插画解释技能选择和预览批准，不将示意图冒充应用截图。

桌面采用双栏首屏，移动端改为单栏，最小宽度 320px；提供可见键盘焦点、语义化导航与标题、足够文字对比。尊重减少动态效果偏好，不依赖动画传递信息。

公开页面仅包含产品介绍、品牌素材和公证安装包，不包含技能库存或仓库内容。版本来自 config/updates.json，下载支持 DMG 和 ZIP；明确 macOS 14+、Intel / Apple Silicon、预览版本与在线更新尚未启用。
