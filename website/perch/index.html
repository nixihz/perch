一个有条理的工作台

从零散配置，到顺手的日常。

面向使用 Codex、Claude Code 的开发者，把项目需要的能力放在一起管理。

01

技能与规则，各归其位

搜索、阅读和整理技能，保留来源信息。将常用协作约定存成 AGENTS 片段，供不同项目复用。

02

每个工具，自己的组合

在同一项目里，为 Codex 与 Claude Code 分别选择技能和规则。切换工具保留各自草稿，共用内容的关联变更会一起预览。

03

工具接入，看得清楚

在 MCP 配置库保存外部服务连接，选择项目或全局范围后预览写入。通过「AI 接入」，让 AI 查询栖集资源并准备配置计划。

如何安装？

下载 DMG，打开后将「栖集.app」拖入 Applications（应用程序）。

需要什么系统和芯片？

需要 macOS 14 或更高版本。同一个安装包同时支持 Apple Silicon 和 Intel Mac，无需选择芯片版本。

会自动修改我的项目吗？

添加项目、浏览技能和选择组合只生成草稿。项目文件写入需要先预览变更，再由你在本机批准。MCP 接口不能代替你批准计划。
